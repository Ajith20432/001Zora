   → Never override this
   → Design stops to respect max_risk_per_trade_pct

   → Initial capital = 25-50% of intended
   → Scale up only after 30+ days profitable
   → Never use margin/leverage

   → Review P&L and trades
   → Verify AI providers are responding
   → Watch for circuit breaker activations

🆘 QUICK FIXES:

"Module not found"
  → pip install requests pandas numpy fastapi uvicorn

"GEMINI_API_KEY not configured"
  → This is CRITICAL! Get free key from: aistudio.google.com/app/apikeys

"AI providers timing out"
  → Increase AI_PROVIDER_TIMEOUT_SEC=15 (default 12)

"Circuit breaker triggered"
  → Expected! Means 4% daily loss hit. System locked for 24h.
  → Reduce MAX_RISK_PER_TRADE_PCT to 0.01 (1%) if too frequent

"No trades placed"
  → Check AI confidence >= 75% threshold
  → Verify TRADING_MODE=paper (not "live" yet)
  → Review logs for signal generation
